# Project guide

## Overview

`alarme` is a Windows desktop reminder app built with Wails 3 and WebView2. It
stores reminders in SQLite under `%APPDATA%\alarme\reminders.db`, stays in the
system tray when its main window is closed, and shows its own small window when
a reminder is due. It does not send Windows notifications. On first launch, it
migrates an older `reminders.json` file when present. A second launch activates
the existing main window. Windows sign-in launches the app hidden to the tray
using the `--startup` argument; startup registration is per-user.

## Structure

- `main.go` creates the Wails app, fixed-size main window, reminder alert
  window, and tray menu. The app embeds `frontend/dist` into the executable.
- `reminders.go` implements reminder scheduling, SQLite persistence, and
  migration. Notification-sound choices are stored in the separate
  `reminder_sounds` table; missing preferences resolve to `No Sound`, so the
  existing `reminders` table needs no migration. `reminders_test.go` contains
  the Go tests.
- `frontend/index.html` defines the main, settings, reminder, and alert-window
  markup. `frontend/src/main.ts` implements UI behavior and Wails bindings.
- `frontend/public/style.css` contains the visual design, themes, and local font
  declarations. The UI uses a compact dark-first layout, with a light theme
  option. Theme choice is stored in WebView localStorage as `alarme-theme`.
- `frontend/public/sounds/` contains the notification chimes generated by
  `frontend/generate_sounds.py`; `No Sound` is the default.
- `build/` contains Wails and platform build configuration. `Taskfile.yml`
  exposes `wails3 build` and related tasks.
- `build/appicon.icon/Assets/wails_icon_vector.svg` is the scalable dark and
  white alarm-clock icon. `build/generate_appicon.py` renders its PNG raster
  asset, which Wails turns into platform icon files during the build.
- `upx-5.2.1-win64/upx.exe` is the checked-in-folder UPX executable used to
  compress Windows builds. `build/windows/compress-exe.ps1` packs a temporary
  copy and then swaps it into place.

## Build

Run `wails3 build` from the project root. The frontend requires Node.js
`^20.19.0` or `>=22.12.0`, plus npm; Go and the Wails 3 CLI are also required.
The Windows build writes `bin/alarme.exe`. After the Go executable is produced,
the Windows build task runs the bundled UPX 5.2.1 with `--best --lzma` to reduce
the executable size. Keep this step after the Go build and before the task
finishes. If UPX is moved or replaced, update its path in
`build/windows/Taskfile.yml`.

The taskbar/executable and tray icons use this app icon. If its design changes,
update both the vector SVG and the raster output with
`python build/generate_appicon.py` before building.

When changing the frontend, edit its source files and rebuild so the updated
assets are embedded in the Windows executable. Preserve the fixed-window,
system-tray, and dark/light theme behavior unless the task requests a change.
